# What I Learned in This Assignment

In this assignment, I learned how to:

- Create Django models for Product, Box, Order, and OrderItem to store data in the database.
- Calculate the total weight of an order using product weight and quantity, and write tests to validate the calculation.
- Check whether a product fits inside a given box using its dimensions.
- Implement logic to find the ideal box based on the box's cost.

This assignment helped me improve my understanding of Django models, business logic, testing, and implementing backend functionality.
